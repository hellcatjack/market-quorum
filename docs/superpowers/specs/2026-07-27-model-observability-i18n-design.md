# 模型可观测性与界面国际化设计

## 目标

解决 Gateway 兼容默认模型、TradingAgents 快慢路由和单次实际调用三种概念混用造成的误解，并为整个 Web 管理端提供可持久化的中文、英文界面切换。

本设计只修改 TradingNG 外部平台层、Gateway 展示语义和 Web 管理端，不修改 TradingAgents 源码。

## 模型语义

系统明确区分三层信息：

1. **Gateway 兼容默认值**：处理显式使用旧 `codex` 别名的兼容调用，只是 Gateway 运行配置，不代表 TradingAgents 评估所用模型。
2. **新任务模型路由**：系统设置中的 `fast` 和 `slow`。界面分别称为“快速分析路由”和“关键裁决路由”。新任务准入时冻结，运行中修改设置不会改变已有任务。
3. **实际模型调用**：每次 LLM 调用记录的路由、别名、物理模型、思考深度、开始和结束时间、耗时、状态与安全错误码。这是判断某次评估实际使用模型的最终依据。

## 模型展示

### 总览容量条

不再显示 Gateway 兼容默认模型。容量 API 增加当前模型路由，容量条以两个紧凑标签展示：

- 快速分析：模型与思考深度
- 关键裁决：模型与思考深度

文案明确这些配置适用于之后准入的新任务。

### 系统状态

Gateway 健康卡只突出接口状态、活动请求、延迟和配置快照。兼容默认值放入折叠的“兼容调用默认值”说明中，并明确 TradingAgents 不以该值作为唯一模型。

模型设置区改名为“评估模型路由”，字段使用“快速分析模型/深度”和“关键裁决模型/深度”。说明快速路由承担分析、工具循环和辩论，关键裁决路由承担研究经理与组合经理判断。

### 评估详情与历史

不可变配置区移除容易误导的通用 Gateway 模型和思考深度，只展示该任务冻结的快速分析与关键裁决路由。历史评估卡也显示两条冻结路由，不再显示兼容默认值。

执行轨迹增加“模型调用”事件。每条事件展示：

- 快速分析或关键裁决
- 实际物理模型
- 思考深度
- 中文或英文状态
- 开始、结束与耗时
- 通过时间戳推导的业务阶段

原始模型别名保留在折叠审计信息中。模型事件与阶段、业务事件和证据共同按真实时间排序。

## 安全模型调用 API

新增 `GET /api/v1/assessments/{run_id}/llm-interactions`，需要 `assessments:read`。

返回结构：

- `items`: 安全模型调用元数据列表
- `source`: `live`、`sealed` 或 `none`
- `complete`: 是否来自完成完整性校验的封存产物

单条记录仅包含顺序号、路由、模型别名、物理模型、思考深度、状态、开始时间、完成时间、耗时和错误码。接口绝不返回 messages、response、token、原始提示词或模型回复。

读取顺序：优先读取数据库登记且通过 SHA-256 校验的 `llm_interactions` 产物；尚未归档的运行中任务读取受控任务目录内的 JSONL。运行中文件只接受完整 JSON 行，忽略可能正在写入的最后一行。文件大小和记录数设置防御性上限。

不存在审计文件时返回空集合；封存文件损坏时返回现有 `artifact_integrity_error`；格式非法时返回安全的审计格式错误，不泄露路径或内容。

## 国际化架构

### 支持范围

支持 `zh-CN` 和 `en-US`。所有导航、页面标题、表单、按钮、提示、状态、执行轨迹、图表标签、系统诊断、验证区和协作区界面文案均进入词典。

以下内容不翻译：证券名称与代码、模型名、供应商名、哈希、原始审计键、原始 JSON 载荷、用户评论、评估报告和投资结论正文。它们是业务数据或审计原文。

### 语言解析与持久化

使用 `I18nProvider` 管理界面语言：

1. 若 `localStorage["tradingng.ui.locale"]` 为支持的语言，使用该值。
2. 否则按 `navigator.languages` 中首个中文或英文偏好解析；中文区域统一映射为 `zh-CN`，英文映射为 `en-US`。
3. 其他浏览器语言回退到 `en-US`。
4. 用户在顶栏切换后立即更新界面、`document.documentElement.lang` 和本地存储；之后始终优先使用用户选择。

顶栏使用可访问的语言选择框，选项固定为“中文”和“English”。界面语言不自动修改新建评估中的报告输出语言。

### 词典与格式化

使用项目内置的类型化扁平词典和 `{name}` 参数插值，不新增运行依赖。中文、英文词典必须拥有相同键集合，缺键在类型检查和词典一致性测试中失败。

日期、时间、百分比和时长使用当前界面的 locale 格式化。领域状态、阶段、事件类型、思考深度和资产类型由共享标签模块翻译；原始标识在需要审计时作为次级代码展示。

## 数据流

1. 系统容量请求返回当前快慢路由，总览直接展示它们。
2. 任务准入时现有配置快照继续冻结快慢路由。
3. Runner 继续写现有 LLM 审计 JSONL，不改变 TradingAgents。
4. 详情页面请求安全模型调用投影；活动任务每五秒刷新，完成任务稳定缓存。
5. 时间线将调用元数据与阶段、事件和证据合并排序。
6. 语言上下文向页面提供翻译和 locale 格式化；切换语言只触发前端重渲染，不重新提交或修改任务。

## 错误与兼容处理

- 旧任务没有快慢路由时显示“旧版任务未记录”，不回退到兼容默认值冒充实际路由。
- 旧 LLM 记录缺少路由字段时显示“路由未记录”，但仍展示可确认的模型字段。
- 模型调用 API 暂时不可用时，详情页保留原时间线并显示局部告警，不影响结论与产物查看。
- 未知状态在用户可见位置显示本地化“未知状态”，同时保留原始代码供审计。
- 原有 REST 字段继续保留以兼容外部调用方；Web 界面停止把 `gateway_model` 当作 TradingAgents 实际模型。

## 测试与验收

### 平台层

- 容量 API 返回当前快速分析和关键裁决路由。
- 历史评估返回冻结的两条路由。
- 模型调用 API 能读取运行中和封存记录、验证封存哈希、忽略原始消息与回复、拒绝损坏数据。
- OpenAPI 契约重新生成并通过契约测试。

### Web 层

- 浏览器中文、浏览器英文、无支持语言回退和本地存储覆盖均有测试。
- 顶栏切换后页面文案和 `html[lang]` 立即更新，刷新初始化仍使用用户选择。
- 总览与系统页不再把 Gateway 兼容默认值标为评估模型。
- 评估详情能按时间显示快慢模型实际调用，并翻译阶段、状态和业务事件名称。
- 中英文分别覆盖总览、新建评估、详情、历史和系统状态主路径。
- 完整执行后运行平台测试、前端测试、lint、类型检查、生产构建与线上健康检查。
