# 结论演化方向状态视觉设计

## 目标

提升“标的档案 / 结论演化”页面中表现验证方向结果的扫读效率，让用户无需逐字阅读即可区分方向正确、方向错误和方向未判定，同时避免把方向判断与收益涨跌混为一谈。

## 方案

- 方向正确：绿色语义，验证卡使用轻微绿色边框和底色，状态徽标显示“✓ 方向正确”。
- 方向错误：红色语义，验证卡使用轻微红色边框和底色，状态徽标显示“× 方向错误”。
- 方向未判定：中性灰语义，状态徽标显示“— 方向未判定”。
- 收益率与 Alpha 不随方向状态着色；它们表达市场表现，不等同于预测正确性。
- 待验证、验证异常和待生成沿用现有样式，不纳入方向结果配色。

## 可访问性

颜色只作为辅助信息。状态同时通过明确文字、符号、边框和徽标轮廓表达；绿色和红色均使用足够深的前景色，并保留现有键盘与屏幕阅读器语义。

## 实现边界

仅修改外部 Web 管理端的结论演化组件、样式和测试，不修改 TradingAgents，不改变 API、数据库或方向判定逻辑。

## 验证

- 组件测试覆盖正确、错误两类结果及对应语义类名。
- 运行前端完整测试、lint、类型检查和生产构建。
- 检查移动端断点下徽标不会造成卡片溢出。
