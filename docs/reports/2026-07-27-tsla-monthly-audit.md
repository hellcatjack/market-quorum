# TSLA 最近一年月度深度评估审计

- 审计日期：2026-07-27
- 覆盖区间：2025-07-31 至 2026-06-25，每月一个已成熟交易日，共 12 次
- 标的与基准：TSLA / SPY
- 评估配置：Deep、中文、市场/社交/新闻/基本面四分析师、历史辅助、Alpha Vantage only

## 结论

工程结论：通过。12/12 次评估成功，36/36 条 1/5/20 交易日验证完成，288/288 个产物重新下载并通过 SHA-256 校验。研究和验证行情均使用 Alpha Vantage，没有 Yahoo 回退。Gateway 完成 323 次 Codex 请求，HTTP 错误、非正常终止和重试均为 0。

投资结论：尚不能证明存在稳定的预测优势。修正评级语义后，1 日、5 日、20 日命中率分别为 41.7%、50.0%、58.3%。样本只有一个标的的 12 个观察值，且 12 次结论全部偏空，不能据此投入自动交易。20 日结果可作为研究校准信号，不能作为单独交易信号。

本轮发现并修复了一个实质性质量问题：`Underweight/Overweight` 是相对基准评级，旧验证却按 TSLA 的绝对涨跌判断。现在 `Underweight/Overweight` 按总回报 Alpha 判断，`Sell/Buy` 仍按标的总回报判断；每条结果同时记录 `direction_basis` 与 `rating-direction.v2`，36 条已有验证已事务化重算并留下运行事件和审计日志。

## 方法和质量门

- 月末日期采用实际交易日；最后一期选择 2026-06-25，使 20 个交易日窗口在审计日之前完整成熟。
- 每期严格串行，后一评估只允许引用其分析日前已经成熟的旧验证，禁止前视。
- 每期必须包含五个完整研究步骤、最终结论、三个验证周期和可校验产物。
- 验证行情必须为 `alphavantage`、`validation.v2`、`alphavantage.v1`、`prices.v1`。
- 从 Alpha Vantage 原始 as-traded OHLC、后续拆股因子和现金分配独立重建标准化 OHLC 与 total-return index，再复算收益、Alpha、MAE/MFE 和方向结果。
- 相对评级按 Alpha 验证；绝对评级按标的总回报验证。

## 历史辅助链

记忆样本数依次为 `0, 1, 2, 3, 4, 5, 5, 5, 5, 5, 5, 5`。所有来源运行互不重复，来源分析日和验证退出交易日都早于当前分析日，没有前视信息。达到上限后系统保留最多 5 个已经成熟、与当前任务相关的验证样本。

本轮只能证明历史样本被正确、可追溯地注入，不能证明模型已经持续自我进化。要验证后者，至少需要多标的、更长周期、固定市场分层，以及同日无历史对照组。

## 建议

1. 继续把系统用于研究和影子验证，不直接作为自动交易决策器。
2. 主要观察 20 个交易日相对基准表现；1D/5D 当前没有显示优势。
3. 增加多头、中性和跨标的样本，避免当前全部偏空造成的类别偏差。
4. 若业务需要价格幅度判断，在外部层增加“目标价或明确缺省理由”的质量字段，但不要为了通过门槛强迫模型伪造目标价。
5. 在下一轮历史辅助 A/B 测试前增加 cohort 隔离，确保旧实验和新实验不会互相进入记忆检索。
